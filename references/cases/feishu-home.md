## 已记录事实
- Hero 背景为深海军蓝/近黑色，顶部有大会通知条 "2026 飞书未来无限大会暨豆包工作开工大会" + "领取大会精华" 蓝色按钮。
- H1 "将 AI 融入各业务环节" 约 40px，白色文字，左对齐。
- 右侧有大会宣传图（3D 抽象彩色丝带/结，蓝紫橙渐变），嵌入浅灰蓝圆角卡片中。
- CTA "观看回放" 为蓝色渐变圆角按钮。
- Hero 下方为白色背景，有 Tab 导航（最佳 AI 实践/精选权益/明星产品/服务与安全）。
- Tab 下方为横向滚动卡片，展示 AI 产品（豆包工作伙伴/豆包工作/飞书 aPaaS），每张卡片有浅蓝/浅绿渐变背景 + 产品 UI 截图。
- 底部有客户 logo 墙（Haier、小米、三一重工、理想、NIO、小鹏、HESAI、地平线等）。
- 页面有弹窗（大会宣传，深蓝色信封造型，含 3D 丝带图 + "领取大会精华" CTA）。
- 字体：Helvetica Neue, PingFang SC, Microsoft YaHei；正文 16px。

## 解释与推断
- 深色 Hero + 白色内容的对比制造强烈节奏，深色区承载品牌叙事，白色区承载产品证据。
- 3D 抽象彩色丝带作为品牌视觉符号，出现在 Hero 和弹窗中形成一致性。
- 横向滚动卡片让多个 AI 产品并列展示，用户可左右浏览。
- 大会弹窗虽然视觉突出，但可能打断首屏阅读（观察时已出现）。
- 客户 logo 墙放在产品卡片下方，用社会证明支撑产品主张。

## 多维标签
- 范围：企业产品/品牌营销
- 页面任务：AI 工作平台品牌叙事与产品矩阵展示
- 叙事：大会事件 → AI 价值主张 → 产品矩阵 → 客户信任
- 布局：深色 Hero 左文右图 + Tab 切换 + 横向滚动卡片 + logo 墙
- 字体：Helvetica Neue / PingFang SC 40px H1；正文 16px
- 图像：3D 抽象彩色丝带、产品 UI 截图、客户 logo
- 材质与色彩：深海军蓝 Hero、白色内容区、浅蓝/浅绿卡片渐变、蓝色品牌 CTA
- 状态证据：Hero + 第二屏已观察；弹窗为实际出现状态

## 条件化迁移
- 深色 Hero + 白色内容的节奏对比适合需要强烈品牌叙事的平台型产品。
  - 不适用于内容为主、需要持续阅读的页面。
- 3D 抽象图形作为品牌符号可在多处复用形成一致性。
  - 不适用于品牌符号尚未建立或图形与产品关联弱的场景。
- 横向滚动卡片适合展示产品矩阵，但需提供明确的滚动提示。
  - 不适用于卡片数量少（≤3）或需要同时对比的场景。

## 不照搬项与反例
- 不继承 40px H1 或 Helvetica Neue 字体。
- 大会弹窗是临时运营内容，不是页面固有设计；不将其作为弹窗设计参考。
- 深色 Hero 中的白色文字需确保对比度，不能直接移植到浅色背景。
