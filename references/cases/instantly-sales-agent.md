## 已记录事实
- 字体声明包含 Averta；实际渲染字体未验证。
- 标题观察值为 40px。
- Hero 使用蓝色渐变与圆角，正文区域使用浅底。
- 渐变、噪点、半透明呈现与简化业务 UI 配合出现。
- CTA 为黑色 pill 形态。
- 流程依次为 setup → learn business → find leads → enrich → personalize → follow up。

## 解释与推断
- 可提炼为软渐变容器承载任务场景，而非蓝色或玻璃材质的通用答案。
- 分步骤叙事可能降低理解 agent 工作链的成本；未测试认知效果。
- 简化 UI 可把注意力引向业务任务，但不证明所示业务已真实执行。

## 条件化迁移
- 当产品价值来自多个连续任务时，用任务链解释输入、推进和结果。
  - 不适用于任务并无固定顺序、却被强行包装成单一路径的产品。
- 当功能难以由一句主张说明时，让简化 UI 对应具体任务场景。
  - 不适用于装饰性伪界面替代真实能力证据的情况。
- 当需要柔和区分展示区与正文时，可考虑渐变容器及克制的材质层次。
  - 不适用于材质损害信息对比、干扰业务阅读或不符合品牌语气时。

## 不照搬项与反例

- 不复制销售流程到非销售任务，也不从展示流程推断产品自动化能力。
