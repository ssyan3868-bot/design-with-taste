# 豆包工作伙伴落地页：AI Agent 产品的轻盈入口

## 来源与观察边界
- 来源：https://aily.feishu.cn/universal/landing?from=feishu_home_nav
- 来源性质：AI Agent 产品落地页
- 整理：2026-09-20；初次浏览：2026-09-20
- 实际语言：英文（标题）+ 中文（内容卡片）
- 桌面范围：CSS 视口 1280×720；文档高度 6235px
- 观察对象：Hero、Agent 工作成果展示区
- 证据载体：截图观察 + DOM 快照

## 已记录事实
- Hero 背景为极浅蓝白渐变（顶部略蓝，向下渐白），整体非常轻盈。
- 顶部有品牌标识 "豆包工作伙伴 M3"（中文 + M3 标签），右上角 "Log In" 蓝色按钮。
- H1 "Your AI team. At work in Feishu." 约 41px（40.96px），Inter 字体，深灰/黑色，居中。
- 副文案 "A dedicated team, ready and proactive everywhere. Tailored in style, skills, and memory—built around you." 灰色，居中。
- CTA "Try Now" 为蓝紫渐变圆角大按钮，带箭头图标。
- Hero 下方展示 Agent 工作成果：顶部有 "Done" 状态行 + 任务完成说明，下方三张卡片（Local file search & analysis / User feedback chat summary / Customer feedback report），每张卡片有浅蓝/浅紫/浅橙渐变背景 + 内容缩略图。
- 字体：Inter（标题）+ Lark 字体栈（正文）；正文 16px。

## 解释与推断
- 极浅蓝白渐变 Hero 营造轻盈、现代的 AI 产品感，不依赖深色或强烈色彩。
- 英文 H1 + 中文内容卡片的多语言混合，反映产品的国际化定位。
- Agent 工作成果用"完成状态 + 三张成果卡片"展示，让抽象的 AI 能力具象化为可感知的输出。
- 蓝紫渐变 CTA 按钮在浅色背景上形成视觉焦点。
- 整体密度较低，留白充足，适合需要传达"轻松上手"感的产品。

## 多维标签
- 范围：企业产品/品牌营销
- 页面任务：AI Agent 产品介绍与试用转化
- 叙事：品牌定位 → 价值主张 → 行动召唤 → 能力证据
- 布局：居中 Hero + 成果卡片展示
- 字体：Inter 41px H1；正文 16px
- 图像：Agent 工作成果缩略图（文档/聊天/报告）
- 材质与色彩：极浅蓝白渐变 Hero、蓝紫渐变 CTA、浅蓝/浅紫/浅橙卡片背景
- 状态证据：Hero + 成果区已观察；后续章节未完整滚动

## 条件化迁移
- 当 AI 产品需要展示"能力"而非"功能"时，用 Agent 工作成果卡片代替功能列表。
  - 不适用于功能复杂、需要详细参数说明的场景。
- 极浅渐变 Hero 适合需要传达轻盈、现代感的产品。
  - 不适用于需要强烈品牌冲击或深色科技感的场景。
- 英文标题 + 本地化内容的混合适合国际化产品的落地页。
  - 不适用于纯本地市场或语言一致性要求高的场景。

## 不照搬项与反例
- 不继承 Inter 字体或 41px H1。
- 蓝紫渐变 CTA 是 Aily 品牌表达，不泛化为"AI 产品用蓝紫渐变"。
- 成果卡片的渐变背景色需根据内容类型调整，不固定为蓝/紫/橙。
