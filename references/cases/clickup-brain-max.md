- 细边界与局部彩光用于视觉呈现。
- 字体声明包含 Plus Jakarta Sans；实际渲染字体未验证。

## 解释与推断
- 图、文与卡片容器可构成单一功能说明单元，而非互不相关的装饰。
- 宽卡与双卡可对应不同内容分量；不是已验证的转化策略。
- 裁切或透视可能引导关注局部能力，但也可能损失界面可读性。

## 条件化迁移
- 当一项功能需要同时解释价值和操作对象时，把文案与 UI 组织为整体。
  - 不适用于文案与图像无关、仅依赖相同容器制造假关联的方案。
- 当功能信息分量有差异时，用宽卡和并列卡形成层级节奏。
  - 不适用于为了对称硬凑卡片、导致内容或阅读顺序失真的页面。
- 当需要强调 UI 中的关键对象时，可谨慎裁切或调整展示角度。
  - 不适用于操作教学、精确数据阅读或透视已影响辨识的场景。

## 不照搬项与反例
- 不把近黑底、彩光或所谓“紫色 AI”作为默认审美菜单。
- 不照搬卡片表皮而丢失用户曾欣赏的图文关联。
- 不把营销 UI 的裁切和透视直接用于真实应用的可操作界面。
