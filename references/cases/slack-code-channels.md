## 条件化迁移
- 产品需要同时解释讨论与交付物且有对应素材时 → 保留主工作区、叠放一个关键结果局部 → 预期建立语义关联。
- 自助开始与联系销售确为两条必要路径时 → 区分主次双 CTA → 预期说明行动选择；否则不为了相似而凑双按钮。
- 浮层遮挡关键上下文、代码缩小后不可读或多浮层竞争时不宜照套；减少展示内容并另测窄屏重排。
