- 多项能力权重与篇幅相近 → 连续等分图文列 → 支持并列理解；不将三列规定为通用数量。
- 功能含义需要具体化 → 选最有辨识度的标签、表格或图表局部 → 避免整张 UI 信息过载。
- 内容较长或功能重要性悬殊时，不强求等高等分；优先调整分组与图文空间。
- 窄屏建议逐项排列并保留图文相邻；此为迁移建议，不是已观察到的响应式行为。
