- 桌面场景可能帮助读者联想到工作情境，发票界面则把氛围连接到具体功能。
- 图像与文案各占一侧，可让重点能力获得独立阅读空间，而非挤入密集功能列表。
- 色彩呼应可能强化整体感；真实业务效果与信任提升未被截图验证。

## 条件化迁移
- 重点功能需要场景化解释且有获授权的高质量照片 → 场景图配精简界面 → 连接使用情境与产品能力。
- 若按用户描述连续展示多张大卡 → 用受控底色区分主题并统一图文关系 → 建立章节节奏；不是已观察行为。
- 素材主体与 UI 竞争时 → 调整裁切、叠层位置与比例 → 保留主体和关键界面信息。
- 功能数量多、需要快速比较或缺少合适授权素材时，不宜把所有功能都做成大幅场景卡。

## 不照搬项
- 不用杂乱库存照片，不用巨大 UI 遮住场景主体；不机械复制绿色与发票业务内容。
- 不因看到暂停符号就添加自动播放，不将用户描述改写为已观察的多卡变色或堆叠动效。
