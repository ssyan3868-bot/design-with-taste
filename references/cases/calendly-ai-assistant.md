# Calendly Callie：左文右界面的逐项讲解

## 来源、时间与范围
- 用户提供的归属 URL：https://calendly.com/ai-assistant；本轮未访问网页，未核验实际地址或首次浏览。
- 收图与整理：2026-09-21；原截图拍摄日未知。
- 已通过 Read 打开用户截图；图片像素 2926×1822，CSS 视口未知。
- 范围仅为 Callie 能力展示区；中文说明与英文邮件 UI 混合，不代表整站语言。

## 截图事实
- 浅色底上左侧为大标题与分组功能文案，组间用细分隔线组织。
- 当前项“直接在您的收件箱中生效”明显，后两项文案与图标淡化。
- 右侧圆角渐变展示区内放置白色简化邮件 UI，主体与背景层次分明。
- UI 可见头像、Cc Callie、请求本周上午安排 30 分钟的文字及 Send Email 按钮。

## 解释与推断
- 明显的当前项与邮件场景对应，可能让读者集中理解一个能力，而非同时处理所有信息。
- 稳定的左右分工适合逐项叙述，但单张图不能证明右侧位置固定或内容会切换。
- 简化 UI 保留请求与行动语义；是否更易理解仍需内容和用户测试。

## 用户确认范围
- 用户方案2：滚动展示，左文、右侧固定区域展示清晰简洁的界面卡片，明确表达内容。
- “右侧固定”“滚动切换”仅记为用户描述，不记为本轮观察到的 sticky、动画或切换机制。
- 确认为“产品功能展示的可选方案”，不是整站喜欢、项目选定或 UI 操作已验证。

## 多维标签
- 用途／叙事：产品营销能力说明；依次讲解多功能、文字与任务场景对应。
- 布局／密度：左侧分组文案、右侧单一展示区；疏朗说明、精简界面。
- 字级／图像：大标题＋当前项强调；邮件 UI 示意；字体家族与精确字级未知。
- 材质／色彩：浅底、细分隔线、圆角渐变区、白色卡片。
- 状态／偏好：单帧当前项可见；方案2用户描述，滚动机制未验。

## 条件化迁移
- 多个功能需要依次解释 → 每项文案对应一张清晰界面卡 → 降低同时阅读的负担。
- 若采用用户描述的固定展示区 → 保持当前文案与图示一一对应 → 避免图文脱节；需另验滚动与可达性。
- 需要并排比较差异时，不宜只显示单项；改用并列卡或直接可见的对照信息。
- 窄屏建议还原为图文逐组相邻，不能让正文与图示分离；这是迁移建议，非截图事实。

## 不照搬项
- 不将后两项的低对比表现照搬到正式说明正文，所有必要内容都应可读。
- 不照搬示例邮箱、人物或英文措辞，不以渐变和巨大卡片掩盖缺少功能说明。

## 证据限制与附件
- 单张截图不能验证 sticky、动画、触发方式、切换机制或滚动进度；不补动态参数与实现技术。
- 未验证 Send Email、真实邮件与日程操作、窄屏、键盘或减少动态效果模式；素材授权未核验。
