## 已记录事实
- Hero 背景为纯白色，顶部导航包含 Brain AI / Product / Solutions / Learn / Pricing / Enterprise。
- H1 "Software to replace all software" 约 38-60px（不同断点有变化），Plus Jakarta Sans 字体，黑色粗体，左对齐。
- 副文案 "Save time. Save money. Infinite productivity." 灰色，与 H1 同行或下方。
- CTA "Get started. It's FREE!" 为黑色圆角按钮 + "Free forever. No credit card." 灰色说明。
- Hero 下方为大面积产品界面截图（项目管理界面），展示侧边栏、列表视图、任务状态等。
- 再下方为白色背景，H2 "60% of work is lost in context – and AI is lost without it" 约 38px，居中。
- 下方有三栏图文（Context Switching / Context Missing / Context Stitching），中间有 3D 抽象线条连接各工具 logo 的视觉隐喻图。
- 字体：Plus Jakarta Sans, system-ui；正文 16px。

## 解释与推断
- 超大 H1 + 极简白色 Hero 让主张本身成为视觉焦点，不依赖装饰或图像。
- "replace all software" 是大胆主张，用黑色粗体最大化冲击力。
- 产品截图紧跟 Hero，用真实界面支撑"全合一"主张。
- 3D 抽象线条连接工具 logo 的视觉隐喻，直观表达"上下文断裂"问题。
- 黑色 CTA 在白色背景上形成强对比，"FREE" 降低行动门槛。

## 多维标签
- 范围：企业产品/品牌营销
- 页面任务：全合一项目管理软件的品牌主张与转化
- 叙事：大胆主张 → 产品证据 → 问题定义 → 解决方案
- 布局：左对齐大字 Hero + 产品截图 + 居中问题区 + 三栏图文
- 字体：Plus Jakarta Sans 38-60px H1 / 38px H2；正文 16px
- 图像：产品 UI 截图、3D 抽象线条连接图
- 材质与色彩：纯白背景、黑色文字/CTA、灰色副文案
- 状态证据：Hero + 问题区已观察；后续章节未完整滚动

## 条件化迁移
- 当产品有明确的大胆主张时，用超大 H1 + 极简白色 Hero 让主张成为焦点。
  - 不适用于主张不够强或需要更多解释的场景。
- 3D 抽象视觉隐喻适合表达抽象概念（如上下文断裂），但需确保隐喻清晰。
  - 不适用于隐喻过于抽象、用户无法理解其含义的场景。
- 黑色 CTA 在白色背景上对比最强，适合需要最大化点击率的场景。
  - 不适用于需要品牌色一致性或柔和调性的场景。

## 不照搬项与反例
- 不继承 Plus Jakarta Sans 字体或 60px H1（需根据主张强度判断字号）。
- "replace all software" 是 ClickUp 的特定主张，不泛化为通用文案模板。
- 3D 线条连接图的风格是 ClickUp 品牌表达，不直接复制到其他产品。
